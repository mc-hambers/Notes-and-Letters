# Notes and Letters 1.1.2

Changes since 1.0.1:

- Moved initial NPC discovery to save loading and replaced repeated scans with event-driven, batched work.
- Rewrote 204 letters with more natural wording, personality and occasional spelling mistakes.
- Couriers now carry two to four verified pocket notes independently of player deliveries.
- Fixed lost signatures and added recovery for affected notes; personal lists remain unsigned.
- Changed inventory titles to Note, Letter, Personal Note and Shopping List.

Existing saves are supported; no new game or save cleaner is required. Build and automated checks passed. These checks do not prove every gameplay path or hitch improvement.
